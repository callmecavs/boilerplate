# boilerplate

Frontend / design engineering boilerplate. Successor to [outset](https://github.com/callmecavs/outset).

## Stack

- Next.js (with `src` directory)
  - TypeScript
  - React Compiler
- Sass (`.scss` syntax) modules
  - Custom, opinionated hard reset
- ESLint
- Prettier
- Stylelint
  - Custom property order
- `pnpm`

## Usage

In the target directory:

```
curl -L https://github.com/callmecavs/boilerplate/archive/refs/heads/main.tar.gz \
  | tar -xz --strip-components=1
```
